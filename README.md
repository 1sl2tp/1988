# 1988 Player

Trình xem YouTube tối giản cho mobile và desktop.

- Dán link YouTube hoặc ID video để xem.
- Mặc định dùng frontend thay thế để có trải nghiệm sạch hơn.
- Có nút đổi máy chủ và fallback sang YouTube chính thức.
- Lưu lịch sử gần đây bằng localStorage.
- Không có quảng cáo riêng của website.

Website: https://1sl2tp.github.io/1988/

> Lưu ý: player YouTube chính thức có thể vẫn hiển thị quảng cáo do YouTube phân phối.
